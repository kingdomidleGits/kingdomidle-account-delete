Kingdom Idle 계정 및 관련 데이터의 삭제는 이메일로 요청하실 수 있습니다. 아래 절차에 따라 요청해 주세요.

계정 삭제 요청 접수 이메일

kingdomidle@ludosinteractive.com

게임에 로그인한 구글 계정(Gmail)으로 위 주소에 메일을 보내 주세요.

처리 기간접수 후 2주 이내

계정 삭제 요청 절차

  1. 1

    게임에 연동된 구글 계정으로 메일함 열기

    Kingdom Idle에 로그인할 때 사용한 구글 계정(Gmail)으로 메일을 보내야 합니다. 보내는 사람 주소가 곧 삭제 대상 계정이 됩니다.

  2. 2

    삭제 요청 메일 작성

    아래와 같이 작성해 주세요. 위의 ‘삭제 요청 메일 작성하기’ 버튼을 누르면 내용이 자동으로 채워집니다.

    받는 사람kingdomidle@ludosinteractive.com
    제목[Kingdom Idle] 계정 삭제 요청
    내용계정 삭제 요청 의사, 게임 내 닉네임 또는 유저 ID(선택)
  3. 3

    메일 발송 및 접수

    보내신 이메일 주소(구글 ID)를 기준으로, 해당 구글 ID로 생성된 게임 계정을 확인한 뒤 담당자가 직접 삭제해 드립니다.

  4. 4

    2주 이내 삭제 · 완료 메일 발송

    요청 접수일로부터 2주(14일) 이내에 삭제가 진행되며, 삭제가 완료되면 요청하신 이메일 주소로 완료 메시지를 보내 드립니다.

메일을 보낸 구글 계정만 삭제할 수 있습니다

계정 삭제는 메일을 보낸 구글 이메일 주소와 동일한 구글 ID로 생성된 계정에 대해서만 진행됩니다. 보낸 주소와 다른 구글 ID에 대한 삭제 요청은 처리할 수 없습니다.

이는 다른 사람이 타인의 계정을 임의로 삭제하는 것을 막기 위한 보호 조치입니다.

✓ 처리 가능

abc@gmail.com에서 발송 → abc@gmail.com 계정 삭제

✕ 처리 불가

abc@gmail.com에서 발송 → xyz@gmail.com 계정 삭제 요청

삭제 및 보관되는 데이터

삭제되는 데이터

  • 게임 데이터 ID 및 해당 계정의 게임 데이터
  • 구글 ID (게임에 연동된 구글 계정 정보)

삭제 요청 시 위 항목이 모두 삭제되며, 삭제된 데이터는 복구할 수 없습니다.

보관되는 데이터

  • 결제 기록
    90일간 보관

결제 기록은 계정 삭제 후 90일간 보관되며, 보관 기간이 지나면 파기됩니다.

참고 사항

  • 기기에서 앱을 삭제(제거)하는 것만으로는 계정과 데이터가 삭제되지 않습니다.
  • 삭제가 완료된 계정과 게임 데이터는 복구할 수 없으니 신중하게 요청해 주세요.
